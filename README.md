## Project: Duka Stock Advisor
An AI-powered assistant that helps shop owners track daily sales, manage stock levels, and receive low-stock alerts.

## How to Run
1. Install requirements: `pip install -r requirements.txt`
2. Create a `.env` file and add your API key: `API_KEY=your_key_here`
3. Run the script: `python main.py`

## API Key Setup
This project uses an environment variable to secure the API key. Never commit your actual `.env` file to this repository.
